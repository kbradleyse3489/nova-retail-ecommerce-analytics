# Nova Retail E-Commerce Growth Intelligence
## Keisha Walker

A fictional business case study exploring revenue, product profitability, customer value, marketing performance, data quality and sales forecasting using Python, SQL and Tableau.

**Data context:** Nova Retail is a fictional company. The supplied practice datasets are synthetic and intentionally contain data-quality issues. This is a portfolio demonstration, not a paid client engagement.

## Available project materials
- [Completed portfolio case study](Nova_Retail_Case_Study.pdf)
- [Original source data and project brief](Nova_Retail_Source_Data.zip)

The source archive includes orders.csv, customers.csv, products.csv, marketing.csv and CLIENT_BRIEF.txt. The case study documents data cleaning, SQL/Python analysis, seasonal-naive versus Holt forecasting and an executive Tableau dashboard.

## Repository status
This initial upload preserves the available case study and original source archive. The completed Python/SQL source, cleaned outputs and Tableau workbook are **not yet included**. This repository is therefore a case-study and data archive, not yet a fully reproducible code release. The documented results have not been independently rerun from this archive.

## Reported case-study findings
- Net retained revenue: $367,943 across 5,622 completed orders.
- Average order value: $65.45; return rate: 6.7%.
- A seasonal-naive forecast outperformed the tested Holt model on the six-month validation window.

These values describe the synthetic case study; they are not real client outcomes or measured business improvements. See the PDF for metric definitions, limitations and recommendations.
